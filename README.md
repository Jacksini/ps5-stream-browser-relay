# PS5 Stream Browser - sign-in relay

One static page, `callback.html`, used as the https redirect address of the
Kick sign-in of [PS5 Stream Browser](https://github.com/Jacksini/ps5-stream-browser).
It forwards what Kick sent to the console on the local network named in the
`state` parameter (private addresses only). It stores and sends nothing else.
